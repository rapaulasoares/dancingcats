# Image Asset Plan

All files go in `/public/images/` as `.webp`. Until a file exists, the game shows a tinted paper placeholder with the filename, so art can arrive in any order.

Tables, charts, the food-chain diagram, the harbor chart, the sampling map, letters and reports are drawn by the game from data. They do not need images.

General guidance for generation (prompts are in [07-image-prompts.md](07-image-prompts.md)): one consistent stylized 3D look, like a high-quality 3D animated film or video game; warm, dignified, lived-in; no text inside images (signs are added by the game); no horror imagery; animals shown impaired, never gory.
